# YouTube Transcriber Pro 🚀

Herramienta sencilla y rápida desarrollada en Python para extraer y transcribir subtítulos o textos de videos de YouTube de forma automática.

## Requisitos
- Python 3.8 o superior
- Librería `youtube-transcript-api`
